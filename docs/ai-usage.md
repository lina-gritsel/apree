# Использование AI

Приложение разрабатывалось совместно с OpenAI Codex. AI использовался для реализации интерфейса и API, подготовки тестов, конфигурации запуска и документации. Работа была разделена между агентами по областям ответственности: frontend, backend, интеграция и качество.

Архитектура и объем были согласованы в диалоге: React, Material UI, NestJS, PostgreSQL, один репозиторий и небольшие модули. Сгенерированный код требует той же проверки, что и любой другой: типизация, линтер, тесты и запуск приложения. CI воспроизводит эти проверки и сохраняет диагностику браузерных сбоев.

Фактические результаты запуска следует смотреть в GitHub Actions и отчете передачи. Использование AI не означает, что каждая строка автоматически проверена или что приложение готово к публичной эксплуатации без дальнейших решений по доступу и размещению.
